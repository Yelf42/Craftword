# Craftword
Craftword is a plugin for PaperMC that allows you import online crosswords from a number of websites, and turn them into big in-game crosswords for players to work on together. 


### IMPORTANT
Just because a website's crossword can be fetched doesn't mean they allow it. If your server is big or generates profit, you should seek permission from the website before using their crosswords. If a website doesn't require permission I will try to indicate it so you know what the safe options are.
